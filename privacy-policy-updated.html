Politique de confidentialité

Dernière mise à jour : 2026-06-01 | Effective : immédiatement

Chez SellerPrint, nous prenons la protection de vos données personnelles au sérieux. Cette politique décrit de manière transparente quelles informations nous collectons, pourquoi nous les utilisons, comment nous les protégeons, et vos droits.

⚠️ Important : SellerPrint est un site d'affiliation pur. Nous gagnons des commissions via les liens Admitad/AliExpress et les revenus publicitaires (Google AdSense, Monetag). Cette politique s'engage à respecter le RGPD (UE) et CCPA (Californie).

1. Données que nous collectons

1.1 Données fournies volontairement

  • Formulaire de contact : nom, adresse e-mail, message
  • Formulaire Boost TikTok : pseudo, URL TikTok, e-mail (via EmailJS)
  • Feedback : avis utilisateur, capture d'écran

1.2 Données techniques (automatiques)

  • Adresse IP : collectée par geolocation API (ipapi.co) pour affichage du pays
  • Cookie & localStorage : historique de navigation, préférences (AdSense, Monetag)
  • User-Agent : type d'appareil, navigateur (pour responsive ads)
  • Referrer : source de visite (Google, Instagram, etc.)
  • Cookies de session : gestion du panier, langue, thème

3. Partage et sous-traitance

Nous partageons vos données uniquement avec :

  • Google (AdSense) : pour affichage de publicités ciblées
  • Admitad : pour commissions d'affiliation & ciblage produits
  • Monetag : pour revenus publicitaires additionnels
  • ipapi.co : pour détection de pays (anonyme)
  • EmailJS : pour envoi de mails de contact (chiffrage en transit)
  • GitHub Pages : hébergement (Californie, conforme GDPR)

Aucun partage avec : data brokers, agences de marketing tiers, ou entreprises sans rapport.

Chaque prestataire agit en tant que sous-traitant et s'engage contractuellement à respecter la confidentialité.

4. Cookies et technologies similaires

4.1 Types de cookies

  • Essentiels (obligatoires) : fonctionnement du site, sécurité, langue
  • Publicités (AdSense, Monetag) : ciblage comportemental (consentement requis)
  • Analytics : Google Analytics, ipapi (consentement requis)
  • Affiliation (Admitad) : tracking clics, commissions

4.2 Gestion des préférences

Une banneau de consentement est affiché au premier chargement. Vous pouvez :

  • ✅ Accepter tout : tous les cookies
  • ⚙️ Personnaliser : choisir par catégorie
  • ❌ Refuser : uniquement essentiels

Vous pouvez modifier vos préférences à tout moment via le bouton "Préférences cookies" en bas de page.

4.3 Désactiver les cookies

Navigateur -> Paramètres -> Confidentialité -> Cookies

⚠️ Attention : désactiver les cookies peut affecter la fonctionnalité du site.
